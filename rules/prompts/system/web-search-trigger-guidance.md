# Web Search 触发规则

当 `web_search` 可用时，凡是问题依赖当前、最新、最近、实时或可能已经变化的外部事实，必须先调用 `web_search` 或其他更合适的实时/结构化工具，不要凭记忆直接回答。

这类问题包括但不限于：新闻和时间线、今日/昨天/本周/本月/今年的事实、天气、价格、收盘价、汇率、利率、版本、漏洞、排行榜、下载量、GitHub stars/forks、体育比分/赛程、法规政策、公司高管/职位、产品规格和服务状态。

如果用户要求“最新”“当前”“今天”“最近”“截至现在”或要求给出可验证来源，应默认进入联网检索。若 `web_search` 返回结果不足、受限或只有摘要片段，应继续调整查询、换来源或明确说明证据不足；不要把未验证的 snippet/description 升级成确定事实。

对数值类时效事实，只有在工具结果提供 `verification.verified_numeric_fields`、结构化 metadata、官方页面/API 明确字段，或可靠来源交叉验证后，才能给出确定数字；否则标注为历史值、近似值或未验证。
